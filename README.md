# 📚 سیستم مدیریت کتابخانه

# 📚 Library Management System

## Description

This project is a **Library Management System**. The current version is a **console-based application** developed in the following programming languages:

- Python
- C++

To run the program correctly, please download the **Data** directory along with the project source code, as it contains the required files and data used by the application.

## Features

- Console-based application
- Implemented in Python and C++
- Library management functionality
- Simple structure suitable for learning purposes

## Notes

> **Note:** The program will not work properly without the `Data` directory.

## Future Plans

A graphical user interface (GUI) version of the application will be released in the future.
